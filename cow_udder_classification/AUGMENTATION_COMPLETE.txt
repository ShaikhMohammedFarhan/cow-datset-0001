## Augmentation Techniques Applied

Each training image was augmented 3 times using these transformations:

1. **Rotation** (±15°)
   - Handles different camera angles
   - Makes model view-invariant

2. **Horizontal Flipping** (50% chance)
   - Creates mirror images
   - Useful for symmetric features

3. **Brightness Adjustment** (0.8x - 1.2x)
   - Simulates lighting variations
   - Improves robustness to lighting conditions

4. **Contrast Adjustment** (0.9x - 1.1x)
   - Handles varying contrast conditions
   - Improves feature discrimination

## Advanced Usage

### Re-augment with Different Settings

If you want different augmentation intensity:

```bash
# Light augmentation (1x per image)
python augment_dataset.py --num-augmentations 1 --augmentation-type light

# Heavy augmentation (5x per image) 
python augment_dataset.py --num-augmentations 5 --augmentation-type heavy

# Extreme augmentation (2x per image)
python augment_dataset.py --num-augmentations 2 --augmentation-type extreme
```

**Note**: This will add MORE augmented images. To replace, delete `*_aug_*.jpg` files first.

### Remove Augmentation

To restore dataset to original state:
```bash
# Remove all augmented files
Get-ChildItem train/normal/*_aug*.jpg -Force | Remove-Item
Get-ChildItem train/diseased/*_aug*.jpg -Force | Remove-Item
```

## Augmentation Levels Explained

| Level | Intensity | Best For | Size |
|-------|-----------|----------|------|
| **Light** | Minimal | Transfer learning, small models | 1.5x original |
| **Standard** | Moderate | Most use cases (APPLIED) | 4x original |
| **Heavy** | Significant | Large datasets, complex models | 6x original |
| **Extreme** | Maximum | Maximum regularization | 5x original |
